# AI Configuration Folder

This folder holds the AI provider credentials for the ClassSense AI Academic
Insight feature. **It is blocked from direct web access** by the `.htaccess`
deny rule — the keys can only be read server-side via `require()`.

## Files

| File         | Purpose                                                              |
| ------------ | -------------------------------------------------------------------- |
| `config.php` | Returns the provider list (Ollama, Groq, Gemini) + models + keys.   |
| `.htaccess`  | Denies all direct web access to this folder.                        |
| `README.md`  | This file.                                                           |

## Providers

Insights are generated by trying providers in this order (`callAIInsight()` in
`api/config.php`); the first success wins, and any disabled/unreachable provider
is skipped automatically:

1. **Groq** — cloud OpenAI-compatible API (`qwen/qwen3.8-27b`), free tier.
2. **Ollama** — local model (`http://localhost:11434/v1`, `qwen2.5:3b`), free and
   unlimited, no key. Requires Ollama to be installed and the model pulled
   (`ollama pull qwen2.5:3b`).
3. **Gemini** — Google Interactions API (`gemini-3.6-flash`), free tier.

## Getting / rotating a key

- **Groq**: <https://console.groq.com/keys> — key starts with `gsk_`. Put it in
  the `groq.api_key` field of `config.php`.
- **Gemini**: <https://aistudio.google.com/apikey> — key starts with `AIza...`.
  Put it in the `gemini.api_key` field of `config.php`.
- Save — no restart needed; the config is read on every request.

## Notes

- `config.php` is git-ignored (see root `.gitignore`) so keys are never
  committed to the repository. (The transfer `.exe` does bundle it — treat the
  `.exe` like a password.)
- The Gemini provider uses the **Interactions API** (`POST /v1beta/interactions`,
  `Api-Revision: 2026-05-20`) because Google retires the legacy `generateContent`
  endpoint for new keys.
- Insights are cached per student/class for 6 hours and re-analyzed only when the
  underlying grades/attendance data changes (2-minute debounce).
